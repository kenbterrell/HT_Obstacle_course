**SVARA HT Obstacle Course**

Net Control Script

**SETUP:**
plug laptop into HDMI and open 2 terminal program windows.

Move window 1 to the big TV, run “./live_course_scoreboard.py”.  Maximize and zoom in to fill screen with scoreboard

in window 2 run “./obstacle_course_checkin_checkout.py”

All commands below are entered into Window 2.
“clear” to reset the scoreboard for a new event
